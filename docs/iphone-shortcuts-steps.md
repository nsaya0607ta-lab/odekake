# iPhoneショートカットで歩数を同期する

Webアプリのまま、iPhoneのヘルスケアに保存されている歩数を「ショートカット」経由で同期するための手順です。

## 事前準備

1. Supabaseへ `supabase/migrations/0010_shortcuts_step_sync.sql` を適用する。
2. アプリで「マイページ → iPhone歩数連携」を開く。
3. 「連携キーを発行」を押し、表示されたキーをコピーする。

連携キーはBearerトークンです。第三者へ共有しないでください。再発行すると古いキーは即時無効になります。

## ショートカット

ショートカットで次の流れを作ります。

1. ヘルスケアから今日の「歩数」を取得する。
2. 今日取得した歩数サンプルの合計を出す。
3. `https://<本番ドメイン>/api/steps/sync` へPOSTする。
4. HTTPヘッダー `Authorization` に `Bearer <連携キー>` を設定する。
5. JSON本文に `steps` として歩数合計を送る。

送信例:

```json
{
  "steps": 8421
}
```

成功時は次のようなJSONが返ります。

```json
{
  "ok": true,
  "date": "2026-08-09",
  "steps": 8421,
  "earnedExp": 16
}
```

`date` を省略した場合、Vercelサーバー側で日本時間の当日を使用します。

## 自動化

iPhoneのショートカットアプリの「オートメーション」で時刻指定実行にします。同じ日に複数回同期しても、`daily_steps` とEXP台帳の同じ日付を更新するため重複加算されません。

最終歩数を取り込みたい場合は夜に1回、ホーム画面の歩数を日中も更新したい場合は昼・夕方・夜など複数回の実行が向いています。

## セキュリティ

- 連携キーからユーザーを特定し、ユーザーIDをリクエスト本文では受け付けません。
- 歩数は0〜200,000歩のみ受け付けます。
- 未来日付は拒否します。
- ショートカット経由では直近7日以内のみ同期できます。
- 連携キーはユーザーごとに1つで、再発行・解除ができます。
- 通常のSupabase APIから連携キーテーブルを直接読み取る権限は付与しません。
