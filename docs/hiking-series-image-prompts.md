# 登山シリーズ アイテム画像生成プロンプト（ChatGPT用）

図鑑「登山シリーズ」の新規アイテム画像を ChatGPT（画像生成）に作ってもらうためのプロンプト集。
既存の雪国シリーズ画像（`public/collection/items/kotatsu.webp` など）と絵柄を揃えるため、
共通スタイル指示 → アイテムごとの個別プロンプトの順にまとめている。

## 使い方

1. 「共通スタイル指示」をそのままChatGPTに送るか、各アイテムのプロンプトの先頭にまとめて貼り付ける
2. 続けて対象アイテムの「個別プロンプト」を貼り付けて生成する
3. 出来上がった画像は正方形→背景透過のPNG/WebPに変換し、下表の「保存ファイル名」で
   `public/collection/items/` に配置する（既存ファイルと同じ命名規則）

## 共通スタイル指示（毎回の先頭に付ける）

```
やわらかい水彩タッチのイラストを1枚描いてください。
背景は真っ白（後で透過処理をするため、背景に模様や影の付いた床などは描かない）。
丸みがあってかわいらしいタッチ、暖かみのある色使い、やさしい光の反射とごく薄い落ち影。
犬（フレンチブルドッグ）のおでかけ図鑑アプリに使うアイテムイラストなので、
アイテムのどこか目立たない場所に、小さな肉球マーク（paw print）をワンポイントで
さりげなく描き込んでください（例: 生地の柄、ラベル、持ち手の一部など）。
構図は正方形、アイテムを中央に大きく、はみ出さない程度の余白でレイアウトしてください。
テキストや文字、ロゴは描かないでください。
```

```
もう片方は木の枝から垂れ下がっているイメージ（枝は端に少しだけ見える程度）。
ロープの繊維がふさふさとほつれた質感。
```

## 生成後のメモ

- 出力は正方形想定。トリミング・背景透過（白背景の除去）をしてから `.webp` 化する
- 実装時は `src/lib/collection/items.ts` の `CURATED_ITEMS` に
  `series: "hiking"` としてエントリを追加し、`image` に上記の保存ファイル名を指定する
- 併せて `src/lib/gacha/prizes.ts` への景品追加、DBの `gacha_rarity_for_item()` への
  レアリティ追記が必要（`src/lib/series.ts` のコメント参照）
