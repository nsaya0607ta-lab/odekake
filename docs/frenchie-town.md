# フレンチーの街づくり（3D試作版）

`/games/frenchie-town` にログインして遊ぶ街づくりゲーム。ミニゲーム一覧とホームのゲームフォルダから開ける。Three.js はゲーム画面で遅延読み込みする。

## 遊び方

- 白コイン800枚と、おうち・木・花だんからスタート。
- 建物、自然、飾りの10種類を選ぶ → 島をタップ（または「場所を選ぶ」のマス目） → 建築を決定。決定前は購入しない。
- 建物は移動・回転・3段階の強化・売却ができる。中央の十字路は犬の通り道として残す。
- 店舗の売上は1分ごとに増え、最大5分分まで受け取れる。6つのお願いは一度ずつ報酬を受け取れる。犬をなでると10枚、同じ犬は1分に1回。
- ドラッグ／スワイプでカメラ回転、ホイール／ピンチで拡大。操作ボタンも用意。犬は建物を避ける経路を歩く。

## 保存と共有の範囲

この白コインは街づくりの試作版専用。既存の赤・青コイン、Supabase残高、ショップには接続しない。課金やランキングにも使わない。

街・白コイン・達成状況は `odekake_frenchie_town_v1:<userId>` のlocalStorageに自動保存する。アカウントごとに分離するが、端末間の自動同期はない。「?」からJSONの保存・復元ができる。復元時には形式・数値・種類・座標・重複を検証し、入れ替え確認を表示する。読み込めない既存値は `:recovery` に残す。複数タブでは新しい保存時刻のデータを取り込む（同時操作を厳密に調停するサーバー台帳ではない）。

招待リンクは街の名前と配置をURLフラグメントに収めたスナップショット。残高・達成状況・userIdは含まない。訪問中は編集・購入・報酬受け取りを停止し、本人の街を置き換えない。ログインが必要。継続更新されるフレンド共有ではない。

## 表示と検証

床はInstancedMesh、基本形状・材質を共有し、同色の静止部品をまとめて描画する。影は配置変更時に更新、pixel ratioは1.5まで。描画が遅い端末は解像度を段階的に下げる。画面非表示時に描画を止め、退出時にイベント・描画ループ・GPUリソースを解放する。WebGLを使えない場合はマス目表示で建築を続けられる。

`node --test scripts/frenchie-town/state.test.mjs`（Node 24以降）で購入の二重払い防止、報酬、収入、復元検証、共有データの範囲、経路探索を確認する。UIはデスクトップ・スマートフォンサイズで建築、カメラ、保存再読込、招待時の本人データ保持を確認する。
