# ぼくのまちづくり

おでかけ独自の箱庭都市ゲーム。OpenTTDの「交通網が街の成長に影響する」という発想を参考にしています。OpenTTDのコード・画像・音源は使用していません。

## 入口と保存
- `/games/town-builder`：ユーザー名「しゅん」でログインしたユーザーに限定。ゲーム一覧の入口とページのサーバー側で同じ判定を行い、他のユーザーは直接URLを開いても404になります。
- `/mini-games-preview/town-builder`：旧体験版URLにも同じログイン・ユーザー名の制限を適用し、本体へリダイレクトします。匿名では街の画面を表示しません。
- `odekake-town-builder:v3:<userId>`に敷地・部品・設備を保存。v3がない場合だけv2、次にv1を読み、街・所持金・日付を残して移行します。旧1マス公園も編集できる小公園へ変換。旧キーはバックアップとして保持し、旧タブの保存で新しいアイテムが消えないように分離します。旧体験版のデータは移しません。
- 保存は通常350msの遅延書き込みに加え、一覧に戻る・ページを離れる・タブを隠す・コンポーネントを閉じる際に最新データを書き込みます。初期化はv3へ明示的な空の記録を残し、v2・v1も削除。旧タブがv2・v1を保存し直しても、再読込で旧街は復活しません。
- 保存先は端末のlocalStorage。別端末への同期・フレンド訪問は未実装です。保存できないブラウザでは画面に表示します。
- 街専用の予算で遊びます。既存コイン・DB・ランキングには影響しません。

## 描画と操作
- 24×24マスのCanvas 2.5Dジオラマ。住宅の屋根・窓・植栽、商店のひさし、工場の煙、駅のホーム、公園の噴水、川・橋、街路灯、昼夜を描画。
- 道路の接続に沿って車が動き、駅を結ぶ線路の実際の経路を列車が往復します。線路を撤去すると運行は停止します。
- 全道具で1本指のドラッグは移動、タップは配置・撤去。道路・線路は「連続敷設」を明示的に選ぶとドラッグで連続工事。L字の経路を使い、斜めの隙間を作りません。建物で塞がれている場合・予算不足は工事全体を取り消します。既存の同じ道路は二重に課金しません。
- 調査・移動モードでドラッグ移動。ピンチ・ホイール・±で拡大縮小。全体表示、マス目表示、昼夜切替。
- 建設予定地のプレビュー。調査から増築（最大Lv.3）。直前20件の工事を取り消せます。取り消しは工事したマス・費用・該当する敷地や部品を戻し、進んだ日付・収支・他のマスの発展は戻しません。
- 矢印キーでマス選択、Enterで操作、Ctrl/⌘+Zで取り消し。遊び方の座標入力でも操作できます。
- 街は画面全体（100dvh）に表示し、アプリ本体のヘッダー・下ナビは外します。予算・街の状況・操作だけを街の上に配置。建物の調査は下部のコンパクトなカード、建設・表示設定・遊び方は開閉式のパネルで、スマートフォンでは道具を選ぶとパネルが閉じます。
- 「街だけを眺める」で表示を隠し、安全な移動モードに切替。戻るボタン・Escapeで操作へ戻れます。Fullscreen API対応ブラウザではブラウザ自体も全画面化し、非対応・拒否時は街だけの表示に切替。
- 調査・撤去は地面の座標だけでなく、手前から屋根・壁のポリゴンを判定。高い建物の屋根を押しても別のマスを選びません。
- 建物の英字ラベルを撤去し、商店は窓・陳列台、駅はホームに沿う看板で表現。建設アイコンは建物と影を枠内に収め、アイコンの煙は省略。工場の煙は建設プレビューの透過度を保持。列車は終点・カーブともに実際の経路の長さで3両の間隔を維持します。道路は全16接続形状で連続した舗装・歩道を描き、車と列車はカーブで位置・向きを滑らかに変えます。橋に隣接する陸地はデッキに連続する傾斜を付け、車両も同じ高さを走行。駅のホーム・屋根・タップ判定は接続された線路の向きに追従し、列車は屋根の下を通ります。
- 描画は画面の更新周期に追従（60Hz画面は最大60fps）・DPR最大2。地面・道路・線路は接続変更時だけ描き直し、建物・植栽は3倍解像度の画像を再利用。画面外のアイテムは描画しません。同じ外観の建物・植栽を共有し、全576マスの街も描画を再利用します。画像キャッシュは最大32MiB分の画素に制限。1.5倍より大きく拡大した場合、画面内の建物と交通網をベクターで描き、細部の解像度を保ちます。一時停止中は街・カメラ・表示サイズが変わったときだけ再描画。非表示タブでは描画とシミュレーションを停止。reduced-motionでは植栽・煙の装飾アニメーションを固定。

## 敷地と部品
- 建設→環境→公園・広場で、公園／広場、2×2（¥580）・3×3（¥1,150）・4×3（¥1,500）から選択。敷地の向きも変更可能。全マスが空いた陸地の場合にだけ、まとめて購入します。川・建物・範囲外・資金不足なら全体を変更しません。
- 敷地購入時は空の土地と枠だけ。木¥70、花壇¥60、ベンチ¥80、噴水¥180、遊具¥240、通路¥25、照明¥90を選び、敷地内をタップして別途購入します。部品一覧は選択後に閉じ、マップと下部の小さな操作バーで配置。通路と設備は同じマスに重ねられますが、同じ層の設備は重複できません。
- 部品の向きは90度ごとに変更。撤去はまず設備、次に通路を外し、購入した敷地を残します。敷地ごとの撤去は編集画面の明示的な確認が必要。購入・撤去・拡張は取り消しに対応し、部品・費用・保存データの並びを復元します。
- 敷地の変更から2×2→3×3→4×3へ拡張。旧1マス公園も拡張可能。差額のみを支払い、既存の部品は保持します。拡張先に建物・川があれば変更しません。
- 空の敷地は公園の満足度・目標達成に加算せず、設備のある敷地を1か所として数えます。敷地の面積や設備に応じた維持費、近所への満足度効果があります。通路は同じ敷地の隣接通路や道路に接続。道路に面した枠には入口を設けます。
- 施設をタップして「部品」から追加。住宅は植栽・テラス・照明、商店は植栽・テラス・照明・看板、工場は資材置き場・緑化帯・太陽光、駅は待合ベンチ・照明、道路は照明。1施設の同じ部品は1回だけ購入可能。取り外しや施設撤去も取り消せます。
- テラスは住宅の定員＋6人、商店の収入＋¥14。商店の看板は＋¥8。工場の資材置き場は＋¥18、太陽光は収入＋¥8・維持費−¥4、緑化帯は近所への悪影響を7ポイント緩和。これらの収支は通常と同じく6日ごとに精算します。

## 発展と経営
- 「小さな集落から」または「更地から」を選択できます。初期予算¥20,000。
- 通常2.5秒で1日。1/2/4倍速と一時停止。6日ごとに税収・輸送収入と維持費を精算。
- 道路沿いに住宅・商店・工場を建設。住宅は1レベル18人。道路を撤去すると人口・税収・雇用への寄与が停止します。
- 公園・商店は近くの住宅の満足度を高め、工場は近くの住宅の満足度を下げます。
- 道路5マス・住宅2棟・満足度45%以上で道路沿いの街が自動発展。鉄道接続で発展周期が24日から12日へ短縮。十分な雇用と満足度で住宅の自動増築。
- 2駅を線路で結ぶと列車運行。線路なしの隣接駅は接続として扱いません。駅の周囲3マス以内の道路付き住宅が輸送収入につながり、住民のいない駅だけでは収入が発生しません。
- 川へ道路・線路を敷くと橋。道路橋¥120、鉄道橋¥160。撤去すると川に戻ります。
- 住宅・緑・鉄道・人口の4つのマイルストーン。報酬は各1回。
