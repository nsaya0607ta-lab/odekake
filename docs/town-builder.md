# ぼくのまちづくり

おでかけ独自の箱庭都市ゲーム。OpenTTDの「交通網が街の成長に影響する」という発想を参考にしています。OpenTTDのコード・画像・音源は使用していません。

## 入口と保存
- `/games/town-builder`：ユーザー名「しゅん」でログインしたユーザーに限定。ゲーム一覧の入口とページのサーバー側で同じ判定を行い、他のユーザーは直接URLを開いても404になります。
- `/mini-games-preview/town-builder`：旧体験版URLにも同じログイン・ユーザー名の制限を適用し、本体へリダイレクトします。匿名では街の画面を表示しません。
- 従来の`odekake-town-builder:v1:<userId>`をそのまま読み、建物を残して保存形式を移行します。旧体験版の`public-town-preview`データは本体へ移しません。
- 保存は通常350msの遅延書き込みに加え、一覧に戻る・ページを離れる・タブを隠す・コンポーネントを閉じる際に最新データを書き込みます。初期化は保存も削除し、再読込で旧街が復活しないようにします。
- 保存先は端末のlocalStorage。別端末への同期・フレンド訪問は未実装です。保存できないブラウザでは画面に表示します。
- 街専用の予算で遊びます。既存コイン・DB・ランキングには影響しません。

## 描画と操作
- 24×24マスのCanvas 2.5Dジオラマ。住宅の屋根・窓・植栽、商店のひさし、工場の煙、駅のホーム、公園の噴水、川・橋、街路灯、昼夜を描画。
- 道路の接続に沿って車が動き、駅を結ぶ線路の実際の経路を列車が往復します。線路を撤去すると運行は停止します。
- 道路・線路・撤去はドラッグで連続工事。L字の経路を使い、斜めの隙間を作りません。建物で塞がれている場合・予算不足は工事全体を取り消します。既存の同じ道路は二重に課金しません。
- 調査・移動モードでドラッグ移動。ピンチ・ホイール・±で拡大縮小。全体表示、マス目表示、昼夜切替。
- 建設予定地のプレビュー。調査から増築（最大Lv.3）。直前20件の工事を取り消せます。取り消しは工事したマスと工事費だけを戻し、進んだ日付・収支・他のマスの発展は戻しません。
- 矢印キーでマス選択、Enterで操作、Ctrl/⌘+Zで取り消し。遊び方の座標入力でも操作できます。
- 街は画面全体（100dvh）に表示し、アプリ本体のヘッダー・下ナビは外します。予算・街の状況・操作だけを街の上に配置。建設・調査・遊び方は開閉式のパネルで、スマートフォンでは道具を選ぶとパネルが閉じます。
- 「街だけを眺める」で表示を隠し、安全な移動モードに切替。戻るボタン・Escapeで操作へ戻れます。Fullscreen API対応ブラウザではブラウザ自体も全画面化し、非対応・拒否時は街だけの表示に切替。
- 調査・撤去は地面の座標だけでなく、手前から屋根・壁のポリゴンを判定。高い建物の屋根を押しても別のマスを選びません。
- 建物の英字ラベルを撤去し、商店は窓・陳列台、駅はホームに沿う看板で表現。建設アイコンは建物と影を枠内に収め、アイコンの煙は省略。工場の煙は建設プレビューの透過度を保持。列車は終点でも3両の間隔を維持します。
- 描画は最大30fps・DPR最大2。一時停止中は街・カメラ・表示サイズが変わったときだけ再描画。非表示タブでは描画とシミュレーションを停止。reduced-motionでは植栽・煙の装飾アニメーションを固定。

## 発展と経営
- 「小さな集落から」または「更地から」を選択できます。初期予算¥20,000。
- 通常2.5秒で1日。1/2/4倍速と一時停止。6日ごとに税収・輸送収入と維持費を精算。
- 道路沿いに住宅・商店・工場を建設。住宅は1レベル18人。道路を撤去すると人口・税収・雇用への寄与が停止します。
- 公園・商店は近くの住宅の満足度を高め、工場は近くの住宅の満足度を下げます。
- 道路5マス・住宅2棟・満足度45%以上で道路沿いの街が自動発展。鉄道接続で発展周期が24日から12日へ短縮。十分な雇用と満足度で住宅の自動増築。
- 2駅を線路で結ぶと列車運行。線路なしの隣接駅は接続として扱いません。駅の周囲3マス以内の道路付き住宅が輸送収入につながり、住民のいない駅だけでは収入が発生しません。
- 川へ道路・線路を敷くと橋。道路橋¥120、鉄道橋¥160。撤去すると川に戻ります。
- 住宅・緑・鉄道・人口の4つのマイルストーン。報酬は各1回。

- `npm run test:town`：保存互換、建築条件、連続敷設の原子性、橋、鉄道経路、人口・増築、会計・マイルストーンの15項目、屋根選択・重なり順・カメラ・透過・文字・列車の8項目、および実ページ・ミドルウェア・下ナビのアクセス制限8項目（しゅん・他のユーザー・未ログイン・旧体験版URL）。
- `npm run typecheck`
- `npm run lint`（既存の別ゲームに警告あり）
- `npm run build`
- 2026-10-10：実際のコンポーネントを読み込むローカル専用ハーネスで1440×900、390×844、844×390、320×568を確認。Canvasが画面全体に一致し、画面スクロール・操作ボタンの見切れや重なりがないこと、建築・屋根選択・増築・取り消し・ピンチ後の移動・工事の中断・保存直後の画面遷移・再読込・初期化、全画面APIの入退場と非対応時の復帰、カタログ全アイコンの画素が枠内に収まること、建物の増えた街の交通・昼夜をブラウザで確認。ハーネスは本番には含めず、匿名公開経路も追加しません。
