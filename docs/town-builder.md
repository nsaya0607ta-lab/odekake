# ぼくのまちづくり

おでかけ独自の箱庭都市ゲーム。OpenTTDの「交通網が街の成長に影響する」という発想を参考にしています。OpenTTDのコード・画像・音源は使用していません。

## 入口と保存
- `/games/town-builder`：ログインユーザーの街。従来の`odekake-town-builder:v1:<userId>`をそのまま読み、建物を残して保存形式を移行します。
- `/mini-games-preview/town-builder`：ログイン不要の体験版。本体とは別の保存キーです。
- 保存先は端末のlocalStorage。別端末への同期・フレンド訪問は未実装です。保存できないブラウザでは画面に表示します。
- 街専用の予算で遊びます。既存コイン・DB・ランキングには影響しません。

## 描画と操作
- 24×24マスのCanvas 2.5Dジオラマ。住宅の屋根・窓・植栽、商店のひさし、工場の煙、駅のホーム、公園の噴水、川・橋、街路灯、昼夜を描画。
- 道路の接続に沿って車が動き、駅を結ぶ線路の実際の経路を列車が往復します。線路を撤去すると運行は停止します。
- 道路・線路・撤去はドラッグで連続工事。L字の経路を使い、斜めの隙間を作りません。建物で塞がれている場合・予算不足は工事全体を取り消します。既存の同じ道路は二重に課金しません。
- 調査・移動モードでドラッグ移動。ピンチ・ホイール・±で拡大縮小。全体表示、マス目表示、昼夜切替。
- 建設予定地のプレビュー。調査から増築（最大Lv.3）。直前20件の工事を取り消せます。取り消しは工事したマスと工事費だけを戻し、進んだ日付・収支・他のマスの発展は戻しません。
- 矢印キーでマス選択、Enterで操作、Ctrl/⌘+Zで取り消し。遊び方の座標入力でも操作できます。
- デスクトップは建設サイドバー、スマートフォンはマップ下の建設パネル。
- 描画は30fps・DPR最大2。非表示タブでは描画とシミュレーションを停止。reduced-motionでは植栽・煙の装飾アニメーションを固定。

## 発展と経営
- 「小さな集落から」または「更地から」を選択できます。初期予算¥20,000。
- 通常2.5秒で1日。1/2/4倍速と一時停止。6日ごとに税収・輸送収入と維持費を精算。
- 道路沿いに住宅・商店・工場を建設。住宅は1レベル18人。道路を撤去すると人口・税収・雇用への寄与が停止します。
- 公園・商店は近くの住宅の満足度を高め、工場は近くの住宅の満足度を下げます。
- 道路5マス・住宅2棟・満足度45%以上で道路沿いの街が自動発展。鉄道接続で発展周期が24日から12日へ短縮。十分な雇用と満足度で住宅の自動増築。
- 2駅を線路で結ぶと列車運行。線路なしの隣接駅は接続として扱いません。駅の周囲3マス以内の道路付き住宅が輸送収入につながり、住民のいない駅だけでは収入が発生しません。
- 川へ道路・線路を敷くと橋。道路橋¥120、鉄道橋¥160。撤去すると川に戻ります。
- 住宅・緑・鉄道・人口の4つのマイルストーン。報酬は各1回。

## 検証
- `npm run test:town`：保存互換、建築条件、連続敷設の原子性、橋、鉄道経路、人口・増築、会計・マイルストーンの15項目。
- `npm run typecheck`
- `npm run lint`（既存の別ゲームに警告あり）
- `npm run build`
- 体験版でPC・スマートフォン幅の描画、建築・ドラッグ、保存再読込、増築・撤去・取り消し、昼夜・カメラを確認。

## 範囲
これは独立した小規模の街づくりゲームです。OpenTTD本体の移植ではありません。車両の路線ダイヤ編集、渋滞・貨物配送、オンライン同期は未実装です。
