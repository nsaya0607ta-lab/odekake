# ぼくのまちづくり（試作版）

## 目的
OpenTTD の「交通網が街の成長に影響する」というアイデアを参考にした、おでかけ独自の箱庭都市ゲームです。
OpenTTD のコード・デザイン・画像・効果音はコピーしていません。OpenTTD 本体は GPL-2.0 ライセンスです。

## 遊び方
- ログイン後 /games/town-builder を開きます。/games にも入口があります。
- 24×24マスのアイソメトリック（2.5D）マップ。スマホはスクロール、±ボタンで縮尺変更。
- 道路、線路、駅、住宅、商店、工場、公園、撤去、マスの調査が可能です。
- 2.5秒でゲーム内1日。6日ごとに収支が動き、一時停止できます。
- 初期資金20,000円。既存の青・赤・白コインと切り離したゲーム内専用資金です。

## 発展のルール
- 住宅・商店・工場は道路に隣接する更地にだけ建てられます。
- 駅が線路で2つ以上つながると輸送収入が発生し、街の成長が加速します。
- 住宅2軒・道路5マス以上を建てると、道路沿いの住宅や商店の周囲に建物が生まれます。
- 6日ごとに住宅・商店・工場・交通収入から道路・線路・駅・公園・工場の維持費を差し引きます。
- 建築物は撤去できますが、費用は返還されません。

## 試作版の制限
- 現時点では車両運行、ドラッグ敷設、旅客・貨物配送、道路渋滞、マルチプレイは未実装です。
- 保存先はログインユーザーごとに分けた、端末内ブラウザのlocalStorageです。
  ブラウザストレージを消去すると街が消え、別端末とは同期しません。
- 将来的にSupabase保存、フレンド街訪問、自由な鉄道運行、道路と鉄道の連続敷設、ゾーニングを追加します。

## 確認項目
1. 道路なしで住宅を置けず、重複建設と資金不足が拒否される。
2. 住宅を道路沿いに作ると人口が増える。
3. 駅2つを線路でつなぐと交通収入と駅接続数が増える。
4. 時間の進行で収支・自動発展が更新され、停止時は止まる。
5. リロードしても保存データが残る。別アカウントの保存データには混ざらない。
6. 初期化する前に確認ダイアログが出る。
7. npm run typecheck / npm run lint / npm run build の実行を推奨。
