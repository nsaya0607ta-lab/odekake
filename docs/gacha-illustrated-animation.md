# 画像素材を使ったガチャ演出

## 素材（`public/gacha/art/`）

ユーザー提供の透明PNG 13枚から作りなおした webp。JPGにすると透明が消えて白いふちが残るので、
必ず透明のまま（webp・アルファつき）で置く。

| ファイル | 中身 |
| --- | --- |
| `machine-body.webp` | マシン本体（835×1222）。看板に「Lucky Paws」と肉球を描きこみ、ドームのまん中ほどガラスが透けるようにしてある |
| `machine-pile.webp` / `machine-dome-mask.webp` | ドームの中のカプセルの山（ドームより少し大きく描いてあり、マスクでドームの形に切り抜く。回すとゆれる） |
| `machine-glass.webp` | 山の上にかぶせるガラス（くもり・光の筋・虹色の反射だけ） |
| `machine-handle.webp` / `machine-door.webp` | ハンドル（まん中が回転の中心）と取り出し口のフタ（上がちょうつがい） |
| `machine-still.webp` | 部品をぜんぶ重ねた1枚絵（ガチャの入り口のカードで使う）。起動画面の `public/splash/gacha-machine.webp` も同じ絵 |
| `capsule-{N…MR}.webp` / `capsule-{N…MR}-s.webp` | カプセル（大・受け皿用の小）。球の大きさをそろえ、SSRのまわりのキラキラは外した。上半分のガラスは中が少し透ける |
| `bg-shop.webp` / `bg-lr.webp` / `bg-mr.webp` | 夜のおもちゃ屋さん・LR・MRの背景 |

部品の位置（ドーム・ランプ・ハンドル・取り出し口）は `gacha-cinematic.module.css` の
`.machine…` に、本体の絵に対する％で書いてある。カプセルのふたと器の合わせ目は
`src/components/gacha/art.ts` の `CAPSULE_SEAM`（帯の上の線の弧）。

## 流れ

- **1回ガチャ**：ハンドルを指で回す（どちら向きでも。タップ・ボタン・キーボードでも回る）→
  ランプが段階的に色を変えて予告（白→金→虹→赤／黒金）→ フタが開いてカプセルが転がり出る →
  タップで開く → 中身が飛び出して結果。結果はタップですぐ次へ進める。
  - MRは、ふつうのカプセルの姿で出てきて、開けかけたところで止まり（亀裂）、MRのカプセルに化けてから開く。
- **10連・100連**：ハンドルを回すと10個が受け皿に飛び出す（確変はここで起きる）。
  N〜SRはタップでその場で開き、SSR以上は大きな演出で開く。「ぜんぶ開ける」で、N〜SRをいっせいに開けてから
  SSR以上をレアの低い順に開ける。100連は10個ずつのセットで、2セット目からはハンドルが自動で回る。
- **AUTO**：タップを待たずに進める（次に回すときも覚えておく）。倍速・スキップ・Escape はいつでも使える。
- **動きを減らす設定**：操作待ちを省いて結果だけを短く見せる。

抽選済みの `AnimationDraw` を見せるだけの演出で、抽選・コイン消費・記録の保存は呼び出し側と既存のAPIが行う。

## 確認

`/gacha-preview` で、N〜MR・10連・確変・100連を、コインの消費と保存なしで再生できる。
