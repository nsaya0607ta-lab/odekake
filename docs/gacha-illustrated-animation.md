# 画像素材を使ったガチャ演出

ユーザー提供の13枚は `public/gacha/illustrated/` に保存しています。
本体・ハンドル・フタ・7種類のカプセルは、SVGの表示マスクで白い余白を隠します。
元の画像を保持し、マシンの部品の位置やカプセルの上下の境目は
`src/components/gacha/illustrated-artwork.tsx` と演出のCSSで合わせています。

- おもちゃ屋の背景で、ハンドルを指で回すか「ハンドルを回す」ボタンを押します。
- マシンと中のカプセルが揺れ、予告ランプが光り、フタが開きます。
- 1回の場合はカプセルが転がり出ます。10連・100連では10個ずつ受け皿へ出ます。
- カプセル本体か「タップして開ける」を押すと、上下が離れ、既存の光の演出と結果表示へ進みます。
- LR・MRは開封するときに専用背景へ切り替わります。
- 倍速の変更では操作待ちを飛ばしません。スキップとEscapeは操作待ち中も使えます。
- 動きを減らす設定では操作待ちを省き、結果を簡潔に表示します。

抽選済みの `AnimationDraw` を表示する演出です。抽選確率・コイン消費・
記録保存の処理は引き続き既存のガチャのAPIと呼び出し側が扱います。
操作を繰り返しても、演出から抽選APIを追加で呼びません。

確認用の `/gacha-preview` では、N〜MR、10連、昇格、100連を
コインの消費と保存なしで確認できます。

## 確認手順

1. `npm run typecheck`、`npm run lint`、`npm run build` を実行します。
2. スマホ幅で7種類の「回す→開ける→結果→終了」を確認します。
3. ドラッグ操作、キーボード操作、操作待ち中の倍速・スキップを確認します。
4. 10連の受け皿と昇格、100連の次の10連へのスキップを確認します。
5. デスクトップ幅と「動きを減らす」設定でも終了できることを確認します。
