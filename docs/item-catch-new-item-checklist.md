# アイテムキャッチ 新アイテム追加チェックリスト

新しいアイテムをアイテムキャッチ（`frenchie-catch-game.tsx`）に追加・調整するときに、まずこのファイルだけ見れば
作業できるようにした早見表。背景・計算式・過去の変更履歴は `docs/minigame-time-balance.md` にあるが、
毎回全部読む必要はない（このファイルの手順通りに直して検算すれば十分）。

## 出現重みプール（追加時にどこを触るか迷ったらここを見る）

`frenchie-catch-game.tsx` の `ITEM_SPAWN_WEIGHTS` はフラットな1回抽選（全アイテムを1つの乱数で選ぶ）だが、
運用上は3つの「プール」に分けて考える。**3プールとも、レアリティランクごとに固定比率を割り当てる
「ランク比率制」**（2026-09-03〜、ユーザー指定）：

**R:30% / SR:18% / SSR:16% / UR:14% / LR:12% / MR:10%**（合計100%）

各プールの「予算」（時間増加系600 / 得点倍率系400 / 出現量アップ・制御系900）に、この比率を掛けた値が
そのランクの予算。そのランクに属するアイテムの人数で均等割りし、10の倍数に丸めた値を
`ITEM_SPAWN_WEIGHTS`に書く。

**該当アイテムが無いランクの予算は「普通のフレブル」(dog)には回さず、単純に不使用のまま**
（`dogWeight`の計算式は完全にノータッチ、`itemPool.length * DEFAULT_ITEM_SPAWN_WEIGHT * (DOG_SPAWN_RATIO / (1 - DOG_SPAWN_RATIO))`
のまま）。そのため**各プールの実効合計（実際にITEM_SPAWN_WEIGHTSに使われている値の合計）は
名目上の予算より小さくなる**（下記表の「実効合計」参照）。新しくそのランクにアイテムを追加すれば、
その分だけプールの実効合計が増える（他ランク・他プールの重みは触らなくてよい）。

プールの実効合計は`node scripts/simulate-item-catch.mjs`実行時に毎回
「プール実効重み合計: ...」として表示されるので、追加前後で比較すること。

### 新アイテムをプールに追加する手順

1. **性質に応じてどのプールに属するか判断する。**
2. そのアイテムのレアリティランクの予算（プール予算×上記比率）を、そのランクの新しい人数で
   割り直す。`ITEM_SPAWN_WEIGHTS`の同ランクメンバー全員の重みを更新する（10の倍数に丸める。
   ランク比率・プール予算自体は変えない）。
3. `simulate-item-catch.mjs`側のプールSet（該当する場合）にも同じIDを追加する。
4. `node scripts/simulate-item-catch.mjs 8000 avoid` を実行し、「プール実効重み合計」行の値が
   想定通り増えているか確認する（未充填ランクが埋まった分だけ実効合計が増える。dogの重みは
   一切変わらない）。
5. 得点倍率系プールに追加する場合は、重みだけでなく`SCORE_MULT_DURATION_*`（発動秒数）・倍率値も
   既存のレアリティ別カーブに揃えること（プールの重み予算を守っても、倍率値や持続時間が既存と
   ズレると得点倍率の重複掛け算リスクが変わってしまう）。

**プールに属さないアイテム**（得点系単発・演出系など）は`DEFAULT_ITEM_SPAWN_WEIGHT`（100）のままでよく、
プールの合計重みには影響しない。

## 追加手順（毎回これをやる）

1. **`src/lib/collection/items.ts`（図鑑本体）に追加する。** ここに無いとミニゲームの`itemPool`に
   一切登場しない静かなバグになる（`prizes.ts`や`item-catch-skills.ts`だけ追加して忘れるケースが過去に実例あり）。
2. **`src/lib/games/item-catch-skills.ts`にルールブック説明文を追加する。**
3. アイテムの性質によって、`frenchie-catch-game.tsx`側で以下を判断する：
   - **時間を直接増やすスキル**（「時間増加系」）にする場合 → `TIME_BONUS_ITEM_IDS`に追加し、
     `LV`テーブルにLv1〜5の秒数（単調増加）を追加。**さらに`TIME_BONUS_CUTOFF_ITEM_IDS`にも追加される
     ことを確認する**（`TIME_BONUS_ITEM_IDS`から自動的に含まれるので通常は何もしなくてよいが、
     `おかえり`のように別枠で追加している特殊ケースだけ手動追加が必要）
   - **出現量アップ系**にする場合 → `SPAWN_DYNAMICS_ITEM_IDS`に追加し、`LV.xxx_SPAWN`配列（Lv1〜5の倍率）を追加
   - **それ以外**（得点系・演出系など） → 上記どちらにも追加しない
4. `ITEM_SPAWN_WEIGHTS`に出現重みを設定する（未指定はデフォルト100）。**新アイテムが1つ増えると
   プール総数が増え、既存アイテム（時間増加系7種＋おかえりを含む）の相対確率が薄まる。**
   完全に相殺したい場合は、既存の時間増加系7種＋おかえりの重みを「プール総数の増加率」
   （`Total(N+1)/Total(N)`）だけ底上げする。目安として、N=89→90程度の増加なら1%前後の底上げで足りる。
5. 数値を変えたら、`LV` / `ITEM_SPAWN_WEIGHTS`（と出現量アップ系なら`LV.xxx_SPAWN`）を
   `frenchie-catch-game.tsx`側で直し、`item-catch-skills.ts`のルールブック説明文と数値を一致させる
   （片方だけ直すと表記と実装がズレる）。
6. `node scripts/simulate-item-catch.mjs 8000 avoid` を実行し、上記の目標値表と見比べる：
   - 全レベル（Lv1〜5すべて。Lv5だけでなく中間レベルもズレることがある）で秒数が単調増加しているか
   - 500秒超えが0%のままか（0%でなくなったらカットオフ実装を疑う）
   - 目標値から大きくズレていたら、手順4の重み調整（時間増加系7種＋おかえりの重み）で微調整する
7. 検算した数値を `docs/minigame-time-balance.md` にも追記する（次回の基準がズレないように）。

## 「時間増加系の出現カットオフ」を壊さないための注意

- プレイヤーの図鑑育成度（R以上アイテムのスキルLv平均）に応じて、プレイ時間が一定秒数
  （平均Lv1→60秒〜平均Lv5→140秒）を超えると時間増加系7種＋おかえりが出現しなくなる仕組みが入っている
  （`TIME_BONUS_CUTOFF_ITEM_IDS` / `timeBonusCutoffSecRef`、詳細は`docs/minigame-time-balance.md`の
  「時間増加系の出現カットオフ導入」節）。
- 新アイテムを時間増加系に追加するときは、この`TIME_BONUS_CUTOFF_ITEM_IDS`（`TIME_BONUS_ITEM_IDS`から
  自動的に含まれる）に確実に入るようにすること。ここに入れ忘れると、カットオフ後もそのアイテムだけ
  出現し続け、プレイ時間が際限なく伸びる不具合に逆戻りする。
- 宝箱(`toy_treasure_puzzle`)・？アイテムはこのカットオフの対象外（意図的な例外なので触らない）。

## 触ってはいけない・慎重に扱うもの

- `MAX_ROUND_SECONDS = 1800`（30分の強制終了）：保険なので削除しない。
- MR3種（ブレブル/ナルシストアー/マフィアー）の出現重み20：得点倍率スタックの暴走対策で意図的に低くしてある。
  新アイテム追加でここを一律の値に巻き込まないこと。
- おかえり(`other_okaeri`)・宝箱(`toy_treasure_puzzle`)の重み：時間バランス調整用に個別チューニング済み
  （レアリティ相応の値ではない）。新アイテム追加の相殺以外の理由で変更しない。
