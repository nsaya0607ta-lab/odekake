# アイテムキャッチ 新アイテム追加チェックリスト

新しいアイテムをアイテムキャッチ（`frenchie-catch-game.tsx`）に追加・調整するときに、まずこのファイルだけ見れば
作業できるようにした早見表。背景・計算式・過去の変更履歴は `docs/minigame-time-balance.md` にあるが、
毎回全部読む必要はない（このファイルの手順通りに直して検算すれば十分）。

## 現在のプレイ時間の目標値（この数値から大きくズレないようにする）

`node scripts/simulate-item-catch.mjs 20000 avoid` の実測値（2026-09-03最新、時間増加系プールから
おかえりの個別チューニング値(300)・出現量アップ制御系プールからブレブルの固定値(20)を廃止し、
両方とも完全にレアリティ別ランク比率制(R30/SR18/SSR16/UR14/LR12/MR10%)のみに統合した後の版。
未充填ランク分はdogへ上乗せしてプール予算を減らさない。N=89基準）。

**注意：ランク比率のみに統合した直後（時間増加系プール予算600のまま）はLv5平均プレイ時間が
181秒→95秒まで落ち込んだ。** おかえり(旧重み300)とブレブル(旧重み20)はいずれもプレイ時間の
体感バランスを保つために個別チューニングされていた値だったため、単純にランク比率へ揃えると
時間増加系の出現ペースが大きく下がってしまう。目標値を維持するため、時間増加系プールの予算を
600→2120（約3.5倍）に引き上げて再チューニングした（出現量アップ制御系プールはブレブル分の
再配分だけで従来予算900のまま維持できている）。

|---|---|---|---|---|
| 1 | 約74秒 | 約71秒 | 約24,000 | 0% |
| 2 | 約102秒 | 約101秒 | 約41,000 | 0% |
| 3 | 約124秒 | 約125秒 | 約61,000 | 0% |
| 4 | 約148秒 | 約151秒 | 約91,000 | 0% |

## 出現重みプール（追加時にどこを触るか迷ったらここを見る）

`frenchie-catch-game.tsx` の `ITEM_SPAWN_WEIGHTS` はフラットな1回抽選（全アイテムを1つの乱数で選ぶ）だが、
運用上は4つの「プール」に分けて考える（時間増加系・得点倍率系・出現量アップ制御系・通常アイテム系）。
**いずれもレアリティランクごとに固定比率（または固定予算）を割り当てる「ランク比率制」**
（2026-09-03〜、ユーザー指定。通常アイテム系のみN〜MRの7ランク、他3プールはR〜MRの6ランク）：

**R:30% / SR:18% / SSR:16% / UR:14% / LR:12% / MR:10%**（合計100%。通常アイテム系プールはこの
比率ではなく、現在の在籍数×100を各ランクの固定予算として直接管理する）

各プールの「予算」（時間増加系2120 / 得点倍率系400 / 出現量アップ・制御系900 / 通常アイテム系6100）に、
この比率を掛けた値がそのランクの予算。そのランクに属するアイテムの人数で均等割りし、10の倍数に
丸めた値を`ITEM_SPAWN_WEIGHTS`に書く。

**該当アイテムが無いランクの予算は、プールの合計から減らさず「普通のフレブル」(dog)の出現重みに
上乗せして消化する**（`TIME_BONUS_UNFILLED_RANK_DOG_WEIGHT` / `SCORE_MULT_UNFILLED_RANK_DOG_WEIGHT` /
`SPAWN_DYNAMICS_UNFILLED_RANK_DOG_WEIGHT`、`frenchie-catch-game.tsx`の`dogWeight`計算に加算。
`simulate-item-catch.mjs`側も同名定数で手動同期）。新しくそのランクにアイテムを追加したら、
対応する定数からそのランクの予算分を差し引き、`ITEM_SPAWN_WEIGHTS`にその予算（同ランクに複数いる
場合は均等割り、10の倍数を維持）で追加する。

**注意：dogへの上乗せは「そのプールの体感的な取得ペースを維持する」ものではない。** dogは他の
全アイテムと同じ1回のフラット抽選に加わるため、dogWeight自体が大きくなるほど時間増加系アイテムを
含む全アイテムの相対選択確率がわずかに下がる（希釈される）。プレイ時間・スコアへの実際の影響は
`node scripts/simulate-item-catch.mjs`で必ず検算すること。

プールの合計重み・未充填ランク分の内訳は`node scripts/simulate-item-catch.mjs`実行時に毎回
「プール重み予算: ...」として表示されるので、追加前後で比較すること。

### 通常アイテム系プール（予算6100、在籍61種すべて等分100ずつ）

2026-09-03、ユーザー指定で新設。特殊効果を持たない「通常アイテム」（得点のみ・演出のみ含む）を
`DEFAULT_ITEM_SPAWN_WEIGHT`任せの管理外状態から、他の3プールと同じ「レアリティ別ランク比率制」の
枠に入れた。新設時点ではいずれのランクも予算÷在籍数がちょうど100になるため、既存の重みからの
変更はなく、プレイ時間・スコアへの影響もゼロ。

| ランク | 予算 | 在籍数 | 1体あたり |
|---|---|---|---|
| N | 2400 | 24種 | 100 |
| R | 700 | 7種 | 100 |
| SR | 900 | 9種 | 100 |
| SSR | 1200 | 12種 | 100 |
| UR | 700 | 7種 | 100 |
| LR | 200 | 2種 | 100 |
| MR | 0 | 0種 | ―（未在籍。初めて追加するときに新規予算を設定しプール総予算6100に加算する） |

定義：`NORMAL_ITEM_IDS`（`frenchie-catch-game.tsx`）/ `NORMAL_ITEM_IDS`（`simulate-item-catch.mjs`、
手動同期）。**このプールに何種追加しても、プール総予算6100自体は変わらない**ため、他の3プールや
「普通のフレブル」(dog)の相対的な出現確率が薄まることはない（Nランクへの大量追加で時間増加系の
出現率が下がる、といった希釈は起きない設計）。

- Listen to the a-(`other_listen_to_the_a`)：重み50固定
- ナルシストアー(`other_narcissist_a`)：重み20固定
- マフィアー(`other_mafia_a`)：重み20固定

これら以外の新アイテムは、性質に応じて上記4プールのいずれかに必ず追加すること
（`DEFAULT_ITEM_SPAWN_WEIGHT`のまま放置しない）。

### 同ランク内で均等に重みを割り振る計算方法（在籍ランクに追加するとき必ずこの手順で計算する）

同じランク内の全アイテム（既存＋追加分）は必ず均等（差が10以内）になるようにする。以下の手順で機械的に計算する：

1. `そのランクの予算 ÷ 新しい在籍数（既存＋追加分）` を計算する（= 基準値）。
2. 基準値を10の倍数に四捨五入する（= 丸め基準値）。
3. `予算 − 丸め基準値 × 在籍数` で差分を出す。
4. 差分 ÷ 10 の個数だけ、対象アイテムのうち何個かを「丸め基準値 + 10」にする。残りは丸め基準値のまま。
   （差分が10未満の端数のみになった場合は、1種だけ+その端数として丸め基準値に足すか、
   誤差として許容する。予算・ランク比率自体は変えない。）
5. こうして決めた重みを在籍ランクの全メンバー分`ITEM_SPAWN_WEIGHTS`に書き込む（新規・既存問わず全員書き直す）。

**計算例（時間増加系プールRランク、予算180に1種追加して4種にする場合）**
```
180 ÷ 4 = 45 → 10の倍数に丸めて 40
40 × 4 = 160（予算180との差20）
20 ÷ 10 = 2種を +10 する
→ 50, 50, 40, 40（合計180）
```

### 新アイテムをプールに追加する手順

1. **性質に応じてどのプールに属するか判断する。**
2. **在籍ランクに追加する場合**：上記「同ランク内で均等に重みを割り振る計算方法」の手順通りに
   そのランクの予算を新しい人数で割り直し、`ITEM_SPAWN_WEIGHTS`の同ランクメンバー全員の重みを
   更新する（ランク比率・プール予算自体は変えない）。
3. **未充填ランクに追加する場合**：対応する`XXX_UNFILLED_RANK_DOG_WEIGHT`定数からそのランクの
   予算分を差し引き、`ITEM_SPAWN_WEIGHTS`に新アイテムをその予算で追加する
   （`frenchie-catch-game.tsx`・`simulate-item-catch.mjs`の両方を同期。同ランクに複数追加する場合は
   同様に「同ランク内で均等に重みを割り振る計算方法」で按分する）。
4. `simulate-item-catch.mjs`側のプールSet（`NORMAL_ITEM_IDS`含む）にも同じIDを追加する。
5. `node scripts/simulate-item-catch.mjs 8000 avoid` を実行し、「プール重み予算」行の
   各プールの合計（2120/400/900/6100）が変わっていないか、プレイ時間・スコアが目標値から
   大きくズレていないか確認する。
6. 得点倍率系プールに追加する場合は、重みだけでなく`SCORE_MULT_DURATION_*`（発動秒数）・倍率値も
   既存のレアリティ別カーブに揃えること（プールの重み予算を守っても、倍率値や持続時間が既存と
   ズレると得点倍率の重複掛け算リスクが変わってしまう）。

**特殊効果を持たない「通常アイテム」は、上記の「通常アイテム系プール」に追加する
（`DEFAULT_ITEM_SPAWN_WEIGHT`のまま放置しない）。** Listen to the a-・ナルシストアー・マフィアーの
3つだけは引き続きどのプールにも属さない単独チューニング枠。

## 追加手順（毎回これをやる）

1. **`src/lib/collection/items.ts`（図鑑本体）に追加する。** ここに無いとミニゲームの`itemPool`に
   一切登場しない静かなバグになる（`prizes.ts`や`item-catch-skills.ts`だけ追加して忘れるケースが過去に実例あり）。
2. **`src/lib/games/item-catch-skills.ts`にルールブック説明文を追加する。**
3. アイテムの性質によって、`frenchie-catch-game.tsx`側で以下を判断する：
   - **時間を直接増やすスキル**（「時間増加系」）にする場合 → `TIME_BONUS_ITEM_IDS`に追加し、
     `LV`テーブルにLv1〜5の秒数（単調増加）を追加。**さらに`TIME_BONUS_CUTOFF_ITEM_IDS`にも追加される
     ことを確認する**（`TIME_BONUS_ITEM_IDS`から自動的に含まれるので通常は何もしなくてよいが、
     `おかえり`のように別枠で追加している特殊ケースだけ手動追加が必要）
   - **出現量アップ系**にする場合 → `SPAWN_DYNAMICS_ITEM_IDS`に追加し、`LV.xxx_SPAWN`配列（Lv1〜5の倍率）を追加
   - **それ以外**（得点系・演出系など） → 上記どちらにも追加しない
4. `ITEM_SPAWN_WEIGHTS`に出現重みを設定する（未指定はデフォルト100）。**新アイテムが1つ増えると
   プール総数が増え、既存アイテム（時間増加系7種＋おかえりを含む）の相対確率が薄まる。**
   完全に相殺したい場合は、既存の時間増加系7種＋おかえりの重みを「プール総数の増加率」
   （`Total(N+1)/Total(N)`）だけ底上げする。目安として、N=89→90程度の増加なら1%前後の底上げで足りる。
5. 数値を変えたら、`LV` / `ITEM_SPAWN_WEIGHTS`（と出現量アップ系なら`LV.xxx_SPAWN`）を
   `frenchie-catch-game.tsx`側で直し、`item-catch-skills.ts`のルールブック説明文と数値を一致させる
   （片方だけ直すと表記と実装がズレる）。
6. `node scripts/simulate-item-catch.mjs 8000 avoid` を実行し、上記の目標値表と見比べる：
   - 全レベル（Lv1〜5すべて。Lv5だけでなく中間レベルもズレることがある）で秒数が単調増加しているか
   - 500秒超えが0%のままか（0%でなくなったらカットオフ実装を疑う）
   - 目標値から大きくズレていたら、手順4の重み調整（時間増加系7種＋おかえりの重み）で微調整する
7. 検算した数値を `docs/minigame-time-balance.md` にも追記する（次回の基準がズレないように）。

## 「時間増加系の出現カットオフ」を壊さないための注意

- プレイヤーの図鑑育成度（R以上アイテムのスキルLv平均）に応じて、プレイ時間が一定秒数
  （平均Lv1→60秒〜平均Lv5→140秒）を超えると時間増加系7種＋おかえりが出現しなくなる仕組みが入っている
  （`TIME_BONUS_CUTOFF_ITEM_IDS` / `timeBonusCutoffSecRef`、詳細は`docs/minigame-time-balance.md`の
  「時間増加系の出現カットオフ導入」節）。
- 新アイテムを時間増加系に追加するときは、この`TIME_BONUS_CUTOFF_ITEM_IDS`（`TIME_BONUS_ITEM_IDS`から
  自動的に含まれる）に確実に入るようにすること。ここに入れ忘れると、カットオフ後もそのアイテムだけ
  出現し続け、プレイ時間が際限なく伸びる不具合に逆戻りする。
- 宝箱(`toy_treasure_puzzle`)・？アイテムはこのカットオフの対象外（意図的な例外なので触らない）。

## 触ってはいけない・慎重に扱うもの

- `MAX_ROUND_SECONDS = 1800`（30分の強制終了）：保険なので削除しない。
- ナルシストアー/マフィアーの出現重み20：得点倍率スタックの暴走対策で意図的に低くしてある。
  新アイテム追加でここを一律の値に巻き込まないこと。
- 宝箱(`toy_treasure_puzzle`)の重み：時間バランス調整用に個別チューニング済み（レアリティ相応の値
  ではない）。新アイテム追加の相殺以外の理由で変更しない。
- **（2026-09-03廃止）** おかえり(`other_okaeri`)の重み300・ブレブル(`other_burebur`)の重み20固定は
  ユーザー指定でランク比率制のみに統合済み。今後この2つを「触ってはいけない個別値」として扱わないこと
  （代わりに時間増加系プールの予算2120自体を、新アイテム追加時の相殺対象として扱う）。
