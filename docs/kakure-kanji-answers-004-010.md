# ステージ4〜10：正解候補の全登録一覧

前の例示だけでなく、部品・単独の画・部品をまたぐ組み合わせを確認した一覧。通常枠は小学校の教育漢字、その他の確認できた単独漢字はシークレット。部首のみ・旧字体や異体字のみ・線を移動／切断／延長しないと作れない候補は登録しない。

曰は日へ統合し、独立した正解にはしない。同じ画の組には、実際の字形に合う正解を一字だけ登録する。森の払い2本は人、思の横画2本と縦画は士を採用。入・土・杁は正解から外す。

| 八 | 小学1年 | 7・8 / 7・12 | 左下の木の左払い7画目と、右下の短い点8画目か、右の木の右払い12画目をえらぶよ。2本が離れて左右に開くので、短い画でも八に見立てる。 |
| 卜 | シークレット | 6・8 | 左下の木から、縦画とその右の短い点だけをえらぶよ。 |

除外・保留した候補：

- **大**：木の縦画を外すと、左払いが横画より上に突き出しません。大に必要な上の部分を足したり伸ばしたりはできないので、正解にはしません。
- **杕**：右下の木から縦画を外しても、大に必要な上への突き出しが残りません。大を作れないので、木と大を組み合わせる杕も正解にはしません。
- **入**：上と右下の払い2本は人に近い形です。右払いの上部がはっきり突き出す入の形にはしません。
- **杁**：右側の払い2本を入にはしないため、木＋入を前提にした杁も外します。
- **三**：横画は3本ありますが、下の2本は横に並んでいます。上下に3本を並べるには線を動かす必要があります。
- **札**：札の右には下で曲がる一画が必要です。森の払いは曲がった一画ではないので作れません。
- **化**：化の右側は曲がる画を含む匕です。森のまっすぐな払いを曲がる画に変えることはできません。
