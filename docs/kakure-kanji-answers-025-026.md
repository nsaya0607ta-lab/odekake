# ステージ25・26：産・額の全登録

線を切断・移動せずに使う。通常は教育漢字、その他はシークレット。曰は日へ統一し、土・士などは実際の形に合う一字だけ。

除外：
- 王：生の縦画は一番上の横画より上へ突き出すため、王にはしません。
- 干：生の縦画は上の横画より上へ突き出すため、干にはしません。
- 士：下の横画が長い土に合わせ、同じ組は土だけを正解にします。
- 午：縦画が上へ突き出す形なので、牛だけを正解にします。

除外：
- 見：右下に必要な曲がり・はねがなく、点を曲がる画には変えません。
- 曰：日と区別せず、日だけを正解にします。
- 名：各の右払いは交差して外へ出るため、夕の内側の点にはできません。
- 宀：うかんむりだけの形は答えにしません。
- 夂：各の上の部首だけの形は答えにしません。
